# Първоначални проектни решения

| Решение | Причина | Статус |
|---|---|---|
| ASP.NET Core MVC с Razor | Покрива изискванията за Controllers и Views и позволява единна C# база за сървър и интерфейс. | Избрано за начало |
| .NET 10 LTS | Наличен е в работната среда, покрива заданието с минимум .NET 8 и има по-дълъг период на поддръжка към 03.11.2026 г. [3] | Избрано; да се съгласува с консултанта |
| MS SQL Server + EF Core | Точно следва посочената технология за база и позволява миграции и seed данни. | Избрано |
| ASP.NET Core Identity | Осигурява регистрация, вход, защитени сесии и роли. | Избрано |
| Роли Client, Master, Admin | Съответстват на трите вида потребители от заданието. | Избрано; етикетите в интерфейса ще бъдат на български |
| Приета оферта създава WorkOrder | Отделя заявката и сравняването на оферти от последващото управление на договорената работа. | Първоначален модел |
| Без реални онлайн плащания в първата версия | Плащанията не са изискване на заданието и разширяват значително обхвата. | Граница на обхвата; да се потвърди |
| Strategy Pattern за известия | Позволява известията в приложението и евентуален имейл да използват общ интерфейс. | Планирано за реализация по-късно |
| Работно име „Майстор до теб“ / `MaystorHub` | Нужно е име за навигация и файлове, докато не се избере окончателно заглавие. | Временно |
