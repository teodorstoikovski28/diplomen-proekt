# Майстор до теб (работно име: MaystorHub)

Дипломен проект: уеб платформа за заявяване и управление на услуги от домашни майстори.

## Цел

Платформата свързва клиенти с майстори и поддържа целия основен процес: търсене по категория, заявяване на услуга, оферта и договаряне на цена и срок, посещения, вътрешни съобщения и оценка след приключване.

## Роли

- Клиент: публикува заявка, избира оферта, следи поръчки и посещения, оставя оценка.
- Майстор: поддържа профил и предлагани услуги, изпраща оферти, управлява поръчки и посещения.
- Администратор: одобрява профили на майстори, управлява категориите и следи сигнали и спорове.

## Технологии

- ASP.NET Core MVC и Razor
- .NET 10 LTS (покрива минимума .NET 8 от индивидуалното задание)
- Entity Framework Core и Microsoft SQL Server / LocalDB за разработка
- ASP.NET Core Identity за регистрация и роли
- Bootstrap от MVC шаблона за адаптивен интерфейс

## Стартиране (след възстановяване на NuGet пакетите)

1. Инсталирайте .NET 10 SDK и SQL Server LocalDB.
2. Отворете `src/MaystorHub.Web/`.
3. Настройте `ConnectionStrings:DefaultConnection` чрез User Secrets или `appsettings.Development.json`.
4. Изпълнете `dotnet tool restore`, после `dotnet ef database update`.
5. Стартирайте с `dotnet run`.

Началните роли и категории се създават чрез seed конфигурацията при прилагане на миграциите. Демонстрационни акаунти ще добавим по-късно, без да публикуваме пароли или ключове. Чувствителните настройки се задават чрез User Secrets или променливи на средата.
